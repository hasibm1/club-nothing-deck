# Club Nothing Fund — Pitch Deck

Slide-deck website for the Club Nothing Fund application: **Bhai Bhai Soundsystem × Everest Sound System** — a month of South Asian bass and sound-system culture at Krazy Gecko Resort, Pokhara, Nepal (September–October 2026).

Single self-contained `index.html` (fonts embedded, no build step), served via GitHub Pages.

Content is edited on the Notion page "Club Nothing Deck — Slide Content" and synced here.
